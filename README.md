# Medical Insurance Cost Analysis

An exploratory data analysis and multiple linear regression practice project using the Kaggle Medical Insurance dataset. The notebook studies how age, BMI, smoking status, region, and number of children relate to insurance charges.

## Contents

- `medical-charge.ipynb` — dataset loading, exploration, preprocessing, feature selection, and model comparisons.
- `Correlation.png`, `checking multi-correlarity.png`, and `model prediction.png` — analysis visualizations.

## Run the notebook

Open `medical-charge.ipynb` in Jupyter or VS Code and run the cells in order. The notebook downloads the dataset with `kagglehub`; you may need internet access and KaggleHub configured in your Python environment.

The notebook reports a best test-set R² of approximately 0.783 for its selected model and data split. Treat this as an educational experiment, not a guarantee of performance on other populations.

## Tools

Python, pandas, NumPy, seaborn, Matplotlib, and scikit-learn.

This project is for learning and is not medical, insurance, or financial advice.
